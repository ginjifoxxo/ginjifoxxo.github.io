# Social logo sources

Website profile URLs and social order are unchanged. All icons are served locally; there are no remote icon requests or runtime icon libraries.

- Facebook, TikTok, Discord, Telegram, X: SVG geometry downloaded 2026-10-08 from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Original viewBoxes and paths are unchanged. These five icons use monochrome CSS masks with background: currentColor.
- BARQ! (2026-10-12): user-supplied, approved transparent artwork, saved unchanged as barq.png. The supplied image already has the orange background removed and uses a pale icy speech bubble with an indigo/blue-grey wordmark and rear bubble. It is displayed directly as a CSS background image, preserving its tones and transparency. Background sizing compensates for transparent margins within the fixed 20px icon box; no character/logo geometry was redrawn or recoloured here.
- Bump (2026-10-12): user-supplied, approved transparent cutout, saved unchanged as bump.png. It is displayed directly as a contained CSS background image in the same 20px box, retaining its original colours without a square app background or monochrome mask.

The previous raster-backed barq.svg and bump.svg masks have been removed. Both approved PNG assets are now present in the repository. Logos remain trademarks of their respective owners; no affiliation or endorsement is implied.
